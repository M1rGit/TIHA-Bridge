# Max ↔ Telegram Bridge

Мост между мессенджером Max и Telegram. Пересылает сообщения из групп Max в TG каналы и обратно.

## Возможности

- Пересылка входящих сообщений из Max групп в привязанные TG каналы
- Отправка сообщений из TG в Max от имени аккаунта
- Пересылка сообщений из ЛС TG бота в выбранный Max чат
- Управление связками Max группа ↔ TG канал через команды бота
- Логирование всех сообщений в SQLite

```

```

## Установка

**Требования:** Python 3.11+
```bash
git clone <repo>
cd max_tg_bridge

python -m venv .venv
source .venv/bin/activate      # Linux/macOS
.venv\Scripts\activate         # Windows

pip install maxapi-python aiogram python-dotenv
```

## Настройка

**1. Создайте `.env` из шаблона:**
```bash
cp .env.example .env
```

**2. Заполните `.env`:**

| Переменная    | Описание                                           |
|---------------|----------------------------------------------------|
| `MAX_PHONE`   | Номер телефона аккаунта Max в формате +79001234567 |
| `TG_BOT_TOKEN`| Токен TG бота от @BotFather                        |
| `TG_USER_ID`  | Ваш Telegram user_id (узнать у @userinfobot)       |

**3. Добавьте TG бота в нужные каналы** как администратора с правом публикации.

**4. Запустите:**
```bash
python main.py
```

При первом запуске Max попросит подтвердить вход — отсканируйте QR-код через приложение. Сессия сохранится в `cache/session.db`.

## Команды TG бота

Все команды работают только в личке с вами (`TG_USER_ID`).

| Команда    | Описание                                          |
|------------|---------------------------------------------------|
| `/start`   | Статус моста и список команд                      |
| `/link`    | Привязать Max группу к TG каналу                  |
| `/links`   | Показать все активные связки                      |
| `/unlink`  | Удалить связку                                    |
| `/setchat` | Выбрать Max чат для сообщений из ЛС бота          |

## Как это работает

### Регистрация чатов

**Max группы** регистрируются двумя способами:
- Автоматически при старте из списка диалогов аккаунта
- Автоматически при получении первого сообщения из нового чата

**TG каналы** регистрируются автоматически когда бот добавляется в канал.

### Создание связки Max → TG

1. Добавьте TG бота в TG канал как администратора
2. Напишите боту `/link`
3. Выберите Max группу из списка
4. Выберите TG канал из списка
5. Связка создана — сообщения из Max группы будут появляться в TG канале

### Пересылка из ЛС бота в Max

1. Напишите боту `/setchat` и выберите целевой Max чат
2. Любой пользователь пишет боту в ЛС → сообщение летит в выбранный Max чат

## База данных

SQLite файл `bridge.db` создаётся автоматически.

| Таблица       | Содержимое                              |
|---------------|-----------------------------------------|
| `max_chats`   | Зарегистрированные Max группы           |
| `tg_channels` | Зарегистрированные TG каналы            |
| `links`       | Связки Max группа ↔ TG канал            |
| `ls_target`   | Целевой Max чат для сообщений из ЛС     |
| `message_log` | Лог всех пересланных сообщений          |

Просмотр логов:
```bash
sqlite3 bridge.db "SELECT * FROM message_log ORDER BY timestamp DESC LIMIT 20;"
```

Просмотр связок:
```bash
sqlite3 bridge.db "SELECT * FROM links;"
```
